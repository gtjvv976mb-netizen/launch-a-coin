# Historical MintDex program reference

Preserved source from MintDex commit1c3a567, not an active CardDex backend. It includes historical sales, bids, royalties and evolving-card instructions which CardDex does not expose or enable. Original program IDs identify the historical implementation; do not deploy or transact with them for CardDex.

CardDex currently runs an isolated local simulation. Its intended real token launch provider is pump.fun. NFT issuance must be independently implemented/configured for fixed creator-selected designs, with no resale royalties and no MintDex resource reuse. The active `chain/sdk` folder is used for offline primitive/verifier reference tests only.
