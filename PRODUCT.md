# CardDex product

For token creators who want their pump.fun launch to have a collectible identity. Choose a permanent premium card design, add original token art and metadata, launch the token paired with its one-of-one creator NFT card, then track token trades and holdings. CardDex is the platform; creators launch their own tokens through the planned pump.fun integration.

The catalog contains 48 fixed designs: eight recognizable trading-card layouts, 14 premium material designs, 20 limited-edition themes, and six dedicated stock-reference designs. Every design has a matching text-free Higgsfield front frame and reverse. The creator's own token image and metadata occupy the card content; decorative artwork does not add theme names or substitute a mascot for that image.

Eight designs carry stock references. Stock GME and the GameStop limited edition use GME / SOL; Stock TSLA uses TSLA / SOL; Stock NVDA uses NVDA / SOL; Stock AAPL uses AAPL / SOL; Stock MSTR uses MSTR / SOL; Stock COIN uses COIN / SOL; the BlackBerry limited edition uses BB / SOL. These are token-pair design references, with no shares, dividends or equity backing implied. The server derives the ticker and pair from the selected immutable design, rather than accepting a freely chosen stock association.

The owner explicitly removed NFT sales, bids and royalties. No automatic card evolution or market-cap design unlocks. Token buy/sell trading remains. Existing MintDex touch rotation, both-face holo shimmer, 3D inspection and case presentation are retained.

Scope: independent local project, no deployment. The current functional build is a clearly labelled simulation with test SOL, simulated token trades and demo creator NFT records. Real SOL does not move, and the demo does not issue pump.fun tokens or on-chain NFTs. Production requires a separately configured and verified pump.fun launch/trading integration and NFT issuance flow; inherited MintDex chain deployment and remote account settings are not activated by this project.
